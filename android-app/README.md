# CNC Pro Tools Android APK

This is an Android WebView wrapper for https://felix10m.github.io/cnc-pro-tools/. It needs internet and loads the live website; it is not an offline native app.

## Download APK
Open GitHub repository → Actions → Build Android APK → latest successful run → Artifacts → CNC-Pro-Tools-Android-APK. Download the ZIP, extract app-debug.apk and install it on Android (enable install from this source if requested).

This APK is a **debug build**, not a Play Store release. To distribute through Google Play, use a signed release/AAB, privacy policy, Play policies and review.

Note: Login via external email links can open the browser rather than the WebView; users may need to sign in again in the APK. Production authentication deep links and a custom app icon are still needed. WebView-based apps may not qualify for Google Play without sufficient app-specific functionality.
