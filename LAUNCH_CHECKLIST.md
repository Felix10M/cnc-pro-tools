# Launch checklist

- [ ] Independently validate all machining formulas and quote examples.
- [ ] Test all buttons and tabs in browser on desktop and mobile.
- [ ] Check data backup and restore using non-sensitive test projects.
- [ ] Create a public GitHub repository and deploy using README.md.
- [ ] Add a contact method controlled by the project owner before soliciting feedback.
- [ ] Invite 10 CNC practitioners to test and record feedback manually.
- [ ] Do not promise AI, cloud sync, subscriptions or production-ready machining recommendations: these features are not implemented.
